# 🎡 Spin & Win

**Spin & Win** is a simple and engaging spinning wheel game built using HTML, CSS, and JavaScript. Users can click the **SPIN** button to rotate the wheel and get a randomized result. It's a fun way to showcase animation, interactivity, and randomness in web development.

## 🚀 Features

- 🎯 Click-to-spin functionality
- 🔄 Smooth wheel animation
- 🧲 Visual pointer to indicate the selected result
- 📱 Responsive layout for various screen sizes
- 🎨 Easy to customize wheel segments and colors

## 🛠️ Built With

- **HTML5** – Markup structure
- **CSS3** – Styling and basic layout
- **JavaScript** – Spin logic and canvas rendering
